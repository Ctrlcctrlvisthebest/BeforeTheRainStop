# 雨停之前 · Before the Rain Stops

千纸鹤主题的 2.5D 合作横版动作游戏。支持 **1、2、3、6 人**，每人控制一只纸鹤。

**[直接开玩](https://ctrlcctrlvisthebest.github.io/BeforeTheRainStop/)** · [备用入口](https://before-the-rain-rooms.zoeli2010xl.workers.dev)

## 怎么玩

| 操作         | 效果                              |
| ------------ | --------------------------------- |
| ← → / A D    | 沿当前视角左右移动                |
| 空格 / ↑ / W | 跳跃；下落时按住滑翔              |
| Q / E        | 旋转世界 90°，切换 X / Z 行走方向 |
| S / ↓        | 整只纸鹤展开成方纸，为同伴挡雨    |
| Shift        | 地面上按住，折成桥供同伴通过      |
| F            | 在起点或存档许愿架旁按住 2 秒修补 |
| R            | 返回最近许愿架（保留耐折消耗）    |

可以跳到同伴头上。找齐钥匙后，全员抵达金色灯门才通关；星星是可选挑战。机关要连续踩住 4 秒，可同时展纸挡雨；多人同时占住两块圆垫，单人只需一块。离开会清空蓄力，开启后保持开启。

四个关卡分别引入转面绕墙、台阶与合作机关、风柱与移动平台、周期雨刃。所有关卡可在大厅选择。手机提供触屏按键，横屏更适合操作。

## 展纸、磨损与修补

- 雨幕交替出现细雨与骤雨；湿度达到 100% 时，该纸鹤回到自己的最近存档许愿架，队伍收藏保留。
- 在地面按住 S / ↓ 展纸，不能同时移动、跳跃或折桥。保护范围是边长 5.2 个世界单位的方形纸面，遮住附近同伴；保护范围按真实空间计算，转面不会扩大范围。
- 展纸者自己承受原雨量的 28%，受同伴保护者每秒晾干 10%。两只纸鹤可以互相遮雨。
- 屋檐、上方实体平台以及无雨处每秒晾干 25%。能站上去的台阶下方也可避雨；跳出屋檐高度就会再次淋雨。
- 第四关可在最后机关蓄力后，到中间的檐亭晾干，再跳过最后的雨刃。单人可以靠展纸与檐亭完成所有关卡。
- 画面中的纸翼变湿后会染上蓝灰色，角色上方和 HUD 显示湿度。展纸有纸面遮雨范围，雨滴会在屋檐与方纸处停止。
- 界面以木质许愿架、挂签和暖灯为主题，背景是昏暗的灰蓝色雨天。右上角「中文 / EN」切换大厅、HUD、操作说明、关卡路牌和提示文字，偏好会保留；切换不会重开关卡或退出房间。
- 飞行振翅幅度从约 9° 增至约 52°，地面与滑翔各有不同幅度，翅根作为旋转中心。

每张纸初始有 **6 格耐折**：每次变为方纸或纸桥消耗 1 格，湿度达到 60% 时消耗 2 格。持续保持形态、松开还原、正常扇翅和跳跃不扣次数；方纸与纸桥直接互换也会消耗一次。折线逐渐加深，纸边会出现破口。

耐折不足时无法再次变形，但仍可移动、跳跃和滑翔。首次经过新的存档许愿架会恢复耐折；也可在起点或存档架旁站稳，**按住 F 两秒**同时修补和晾干，移动、跳跃或变形会中断。R 返回和落水重生都不会凭空恢复耐折，因此需要在架旁修补。

## 背景音乐

原创无歌词器乐《檐下的愿望》：72 BPM、三拍子、80 秒循环，包含程序合成的拨弦、柔和键音、笛音、远钟与低音量雨声。没有使用外部歌曲或采样。成品为 44.1 kHz 立体声 AAC，约 1.5 MB，随网页一起托管，不依赖音乐 API。

右上角「播放音乐」可以立即播放或暂停，旁边的下拉按钮打开曲目进度与音量。首次开始冒险也会启播；手动关闭的选择和音量会保留。大厅切换关卡、语言或返回大厅时继续播放，关卡内音量自动降低，切到后台暂停，回来后恢复；浏览器若拒绝自动恢复，可再次点击音乐按钮。

`public/audio/rain-wishes.m4a` 是游戏实际使用的音频；`scripts/compose_music.py` 保存完整乐谱、合成和混音程序，可用 Python + NumPy 重新生成 WAV。循环边界包含上一轮的混响尾音，音乐不需要每次从零淡入。效果音跟随同一音量和开关。

## 联机

选择 2 / 3 / 6 人并创建房间，把邀请链接或 8 位房间码发给朋友。人数齐且所有人连接后，由房主开始。所有人独立操作，任何玩家按 Q 都会转动全队视角，转面前需要配合。

房间自创建起保留 24 小时。刷新原标签页可以恢复座位；另一个独立标签页可以加入为其他玩家。掉线时关卡暂停，重连后继续。重开和下一关需要全员同意。没有公开匹配、聊天或机器人补位。

单人使用本地物理模拟；多人通过 WebSocket 发送操作，由服务器每秒运行 60 次物理更新、每秒发送约 15 次权威快照。客户端做最多 100 毫秒预测及画面平滑。仅服务器决定收藏、机关与通关结果。不是同屏轮流操作。

## 本地开发

需要 Node.js 24：

```sh
npm ci
npm run types
npm run build
```

分别打开两个终端：

```sh
npm run dev:server
```

```sh
npm run dev
```

默认页面 `http://127.0.0.1:5173`，Vite 将 `/api` 和 WebSocket 转发至本地 `8788` 端口。单人不需要房间服务。

## 发布

GitHub Pages 托管前端，Cloudflare Workers + Durable Objects 托管联机房间。

- GitHub 仓库 Pages 来源为 **GitHub Actions**，推送 main 后自动测试、构建并发布。
- 默认房间服务写在 `.env.production` 和发布工作流的公开配置中。可使用仓库变量 `VITE_ROOM_SERVER_URL` 覆盖。
- `wrangler.jsonc` 的 `ALLOWED_ORIGINS` 已包含 `https://ctrlcctrlvisthebest.github.io`。如换域名，增加其 origin 后重新部署后端。
- 资源路径使用 `./`，适用于 GitHub Pages 仓库子路径。

重新发布房间服务及备用入口：

```sh
npm run build
npm run deploy:server
```

部署凭证由本机 Wrangler 管理，不放入网页或仓库。浏览器的房间座位凭证只保存在自己的 sessionStorage，通过 WebSocket 首次认证消息或 HTTPS Authorization 头发送，不放入邀请链接。

Cloudflare 用量取决于账号方案和游戏时长。房间在无连接和过关时停止模拟，有创建频率限制，并在 24 小时后清理。

## 测试

```sh
npm test
npm run build
npm run test:integration
```

集成测试需要运行本地房间服务；也可指定已部署服务：

```sh
TEST_SERVER=https://before-the-rain-rooms.zoeli2010xl.workers.dev npm run test:integration
```

31 项单元测试覆盖四关的真实操作通关路线（无传送）、跳跃滑翔、两轴碰撞、叠站和折桥、个人存档、各人数机关与全员过关、移动平台、输入校验与房间权限，以及湿度、屋檐恢复、互相挡雨、湿透回存档、旧房间兼容、机关蓄力、耐折计费、湿纸额外磨损、耗尽后移动、检查点修复和连续修补。另有 3 项真实 WebSocket 集成测试覆盖 2 / 3 / 6 人同步、座位隔离、视角共享、展纸状态、耐折和修补同步、掉线暂停和重连。

## 结构

- `src/game.ts`：确定性 60 Hz 物理与四个手工关卡。
- `src/weather.ts`：雨区、檐亭、雨势与方纸遮雨范围。
- `src/scene.ts`：Three.js 纸鹤、平台、光照、相机旋转与动画。
- `src/main.tsx`、`src/style.css`：大厅、操作、HUD、触屏按键、结算。
- `src/i18n.ts`：中文、英文界面和路牌翻译。
- `src/audio.tsx`：背景音乐、音量、后台暂停和音效。
- `src/api.ts`：房间请求、WebSocket 与自动重连。
- `src/room.ts`：人数、权限、加入与投票。
- `server/worker.ts`：房间路由、权威模拟、SQLite 存档与过期回收。
- `tests/journey.ts`：使用正常输入完成四关的自动化路线。
- `.github/workflows/pages.yml`：Pages 自动发布。

几何纸鹤、平台和音效由代码生成；没有复用 SpriteQuest 或 PICO PARK 的关卡、美术或音频。字体为 Google Fonts Noto 系列，有系统字体回退。
