# 雨停之前 · Before the Rain Stops

千纸鹤主题的 2.5D 合作横版动作游戏。支持 **1、2、3、6 人**，每人控制一只纸鹤。

**[直接开玩](https://ctrlcctrlvisthebest.github.io/BeforeTheRainStop/)** · **[独立地图编辑器](https://ctrlcctrlvisthebest.github.io/BeforeTheRainStop/editor.html)** · [备用入口](https://before-the-rain-rooms.zoeli2010xl.workers.dev)

## 怎么玩

| 操作         | 效果                              |
| ------------ | --------------------------------- |
| ← → / A D    | 沿当前视角左右移动                |
| 空格 / ↑ / W | 跳跃；下落时按住滑翔              |
| Q / E        | 旋转世界 90°，切换 X / Z 行走方向 |
| S / ↓        | 整只纸鹤展开成方纸，为同伴挡雨    |
| Shift        | 地面上按住，折成桥供同伴通过      |
| F            | 在起点或存档许愿架旁按住 2 秒修补 |
| R            | 返回最近许愿架（未存档物品复位）  |
| T            | 快速重开本关；联机时发起重开投票  |

可以跳到同伴头上。找齐钥匙后，全员抵达金色灯门才通关；星星是可选挑战。机关要连续踩住 4 秒，可同时展纸挡雨；多人同时占住两块开门踏板，单人只需一块。离开会清空蓄力，开启后保持开启。

共有 **17 个关卡**，全部可在大厅选择，通关后按顺序继续；第十七关后回到第一关。前四关依次引入转面绕墙、低檐断桥与合作机关、风柱与移动平台、侧向断桥与篷下旺火。第五至八关组合已有玩法；第九至十二关为更高难度的挑战关，第十三至十七关延续最后两关的强度，组合侧向纸桥、窄渡接力、高台折返和火廊。

## 独立地图编辑器

打开 [雨中造景](https://ctrlcctrlvisthebest.github.io/BeforeTheRainStop/editor.html)，选择组件后点击画布放置。支持俯视、正面、侧面视图，精确属性、拖动吸附、复制、删除、撤销重做、17 关模板、自动保存和 JSON 导入导出。

编辑器提供五步制作引导，以及纸桥、平台、渡台、天气和路线的分类说明。选择物件后，右侧会解释它的用途和参数；移动平台可播放或拖动时间预览轨迹。

- 纸桥组件只放一次，两岸桥钉和接桥踏板自动生成；单人按住 Shift 2 秒自动接通，不需要另外加桥钉。
- 渡台就是开启往返运动的平台。选择渡台种类会开启运动，关闭运动会还原普通平台标记。移动方向为 X / Z，单侧距离是中心到一端，周期是一整轮往返。
- 普通平台、台阶、墙体共用长方体碰撞；尺寸和顶面高度决定形状。台阶种类不会自动生成楼梯。低檐、侧栏为纸桥专用部件。

「试玩地图」使用正式游戏同一套物理、雨水、纸桥、耐折、存档和引导规则，当前为单人试玩，Esc 返回编辑。新增关卡本身就使用同一种 JSON 格式。导出的文件可以重新导入继续制作，也可以注册到正式的 1 / 2 / 3 / 6 人关卡表。详细字段和接入步骤见 [MAP_FORMAT.md](MAP_FORMAT.md)。

手机提供触屏按键，横屏更适合操作。小地图随实际关卡范围缩放，相机会向纸鹤面朝方向预留视野。

## 随路引导与玩法图解

默认开启「引导开」。每关从移动开始，当前目标卡会随实际进度提示走、跳、转面、拾取、存档、搭桥、搭渡台和开门；到达后自动进入下一步。场景中的金色空心路标和小地图目标圈对应同一个落脚点，小地图同时标出钥匙、许愿架与小火。死亡返回后，引导回到当前存档段；漏拿的钥匙会提醒沿路返回。

桥钉未对齐时先教走位，对齐后才提示 Shift；搭桥者、过桥者分别看到保持纸桥与踩住对岸方板的说明。渡台太远时提示等待，拿到途中钥匙、接近对岸后才提示起跳。高湿、烘烤过久、前方旺火、耐折不足时有对应提醒。

点击目标卡的「看图学这一步」直接打开相关主题，也可随时打开「操作说明」。图解分为走跳、转面、纸桥、雨火、收集存档、风柱渡台、机关通关七类，每类有示意图和三步说明。**单人看图解时暂停物理和计时**；多人阅读时停止自己的按键输入，房间继续运行，界面会提示先找安全位置。中英文均支持。右上角可关闭引导，选择会保留。

## 本地通关纪录

正式关卡通关后，自动将本次用时与该关的本地最佳比较；首次完成即保存，之后只有严格更快的成绩才覆盖，相同或更慢的成绩保留原纪录。单人、双人、三人、六人分别记录，大厅选关和结算页都能查看；中英文切换不影响成绩。

用时沿用关卡计时，显示为「分:秒」，秒数保留小数点后一位，包含死亡和返回存档后的重试。已有成绩保留原始精度用于比较；不足 0.1 秒的提升会单独提示。单人暂停说明或切到后台、联机因队员掉线而暂停的时间不计入；多人查看说明时房间继续运行，时间也继续累计。整关重开从零计时，联机以服务器确认全队通关的用时为准。编辑器试玩不计入正式纪录。

按 **T**、点击游戏工具栏的「快速重开」或手机左下角「重开」，即可从本关出生点重新挑战；结算页也能直接重开本关。计时、钥匙、星星、存档点、机关和纸张状态全部恢复为本关初始状态，已保存的最佳纪录保留。单人立即重开，联机在全员同意后一起重置。**R / 回存档**仍用于返回最近许愿架，不清零计时。

纪录保存在当前浏览器、当前站点的本地存储中，刷新或重开网页后保留；清除网站数据会删除纪录，其他浏览器、设备及备用入口的纪录分别保存。浏览器不允许保存时，结算页会提示，游戏仍可继续。

## 收集物与存档

钥匙和星星先由拾取它的纸鹤随身携带；**到达下一个新的存档许愿架才正式保存**。回到已经点亮的同一个架子不会补存新拾取物，F 修补也不会存物品。灯门会保存最后一段收集。

坠落、湿透、旺火烧毁、烘烤脆裂或按 R 返回时，**该纸鹤尚未存档的物品回到原位置，需要重新拾取**；已存物品保留。多人各自记录携带物，队友携带或已经保存的物品不会因别人死亡而丢失。已接通的木桥与已打开的机关继续保留。

界面下方显示自己的未存档钥匙、星星以及下一个架子的提示；存档成功和死亡丢失物品时有对应提示。联机刷新或重连保留当前房间的携带归属与存档结果；房间到期或全员重开本关时重新开始。旧版本房间已收集的物品按已存档处理。

## 纸桥是怎么合作的

第二、七、十一关的低檐断口与第四关的侧向断口留有 2.6 单位缺口，低檐限制起跳，不能直接跳跃或滑翔过去。第四关需要先按 Q 切到侧面对齐桥钉。

1. 一名队员站在金色桥钉旁，按住 Shift，纸桥固定横跨缺口；保持形态不额外消耗耐折。
2. 另一名队员从纸面走到对岸，连续踩住金色方形踏板 2 秒，接通永久木桥。只在对岸等候但没有经过纸面，无法触发。
3. 搭桥者松开 Shift，所有人沿木桥继续前进。未接通时提前松手，搭桥者退回原岸，蓄力清零。
4. 单人没有接应者，桥钉会在按住 Shift 2 秒后自动放下木桥。接通木桥后，关卡末端的开门踏板才会供能。

桥身固定在实际空间，队友切换视角不会让它突然旋转。木桥在本轮关卡内保留，重开本关后恢复断口。

## 展纸、磨损与修补

- 雨幕交替出现细雨与骤雨；湿度达到 100% 时，该纸鹤回到自己的最近存档许愿架，已存物品保留，自己未存档的物品复位。
- 在地面按住 S / ↓ 展纸，不能同时移动、跳跃或折桥。保护范围是边长 5.2 个世界单位的方形纸面，遮住附近同伴；保护范围按真实空间计算，转面不会扩大范围。
- 展纸者自己承受原雨量的 28%，受同伴保护者不再继续淋湿。两只纸鹤可以互相遮雨，但遮雨不能烘干。
- 屋檐、上方实体平台以及无雨处只停止淋湿。只有进入小火堆的火光圈，湿度才会降低；跳出屋檐高度会再次淋雨。
- 第四关需要在途中小火堆旁烤干，再展纸踩机关，最后跳过旺火。纸已烤干后应及时离开，不要继续在篷下火边等待。
- 画面中的纸翼变湿后会染上蓝灰色，角色上方和 HUD 显示湿度。展纸有纸面遮雨范围，雨滴会在屋檐与方纸处停止。
- 界面以木质许愿架、挂签和暖灯为主题，背景是昏暗的灰蓝色雨天。右上角「中文 / EN」切换大厅、HUD、操作说明、关卡路牌和提示文字，偏好会保留；切换不会重开关卡或退出房间。
- 飞行振翅幅度从约 9° 增至约 52°，地面与滑翔各有不同幅度，翅根作为旋转中心。

每张纸初始有 **6 格耐折**：每次变为方纸或纸桥消耗 1 格，湿度达到 60% 时消耗 2 格。持续保持形态、松开还原、正常扇翅和跳跃不扣次数；方纸与纸桥直接互换也会消耗一次。折线逐渐加深，纸边会出现破口。

耐折不足时无法再次变形，但仍可移动、跳跃和滑翔。首次经过新的存档许愿架会恢复耐折；也可在起点或存档架旁站稳，**按住 F 两秒**修补，移动、跳跃或变形会中断。修补不清除湿度或烘烤程度；R 返回和落水重生不会恢复耐折。

## 小火烤干，旺火烧毁

每个篷子里都有小火堆，火光圈表示烘干范围（半径 1.45、高度差低于 0.9）。靠近时每秒降低 26 点湿度，同时增加 12.5 点烘烤程度；满湿纸约 4 秒能烤干，从零连续烤约 8 秒会脆裂失败。纸边逐渐变成焦褐色，达到 65 会警告，达到 100 返回最近许愿架。离开火光圈后每秒降低 22 点烘烤程度，湿度不会因此下降。转面和展纸不能清除热量。

第四关原地刺已替换成有屋篷遮雨的旺火，持续燃烧，接触主体火焰会直接烧毁；展纸不能挡火，须提前起跳跨过。小火与旺火有不同体积、颜色和标签。失败只影响当前纸鹤，自己未存档的钥匙、星星复位，已存物品和已经接通的木桥保留；失败原因和复位数量会显示在画面上。

## 背景音乐

原创无歌词器乐《檐下的愿望》：72 BPM、三拍子、80 秒循环，包含程序合成的拨弦、柔和键音、笛音、远钟与低音量雨声。没有使用外部歌曲或采样。成品为 44.1 kHz 立体声 AAC，约 1.5 MB，随网页一起托管，不依赖音乐 API。

右上角「播放音乐」可以立即播放或暂停，旁边的下拉按钮打开曲目进度与音量。首次开始冒险也会启播；手动关闭的选择和音量会保留。大厅切换关卡、语言或返回大厅时继续播放，关卡内音量自动降低，切到后台暂停，回来后恢复；浏览器若拒绝自动恢复，可再次点击音乐按钮。

`public/audio/rain-wishes.m4a` 是游戏实际使用的音频；`scripts/compose_music.py` 保存完整乐谱、合成和混音程序，可用 Python + NumPy 重新生成 WAV。循环边界包含上一轮的混响尾音，音乐不需要每次从零淡入。效果音跟随同一音量和开关。

## 联机

选择 2 / 3 / 6 人并创建房间，把邀请链接或 8 位房间码发给朋友。人数齐且所有人连接后，由房主开始。所有人独立操作，任何玩家按 Q 都会转动全队视角，转面前需要配合。

房间自创建起保留 24 小时。刷新原标签页可以恢复座位；另一个独立标签页可以加入为其他玩家。掉线时关卡暂停，重连后继续。重开和下一关需要全员同意。没有公开匹配、聊天或机器人补位。

单人使用本地物理模拟；多人通过 WebSocket 发送操作，由服务器每秒运行 60 次物理更新、每秒发送约 15 次权威快照。客户端做最多 100 毫秒预测及画面平滑。仅服务器决定收藏、机关与通关结果。不是同屏轮流操作。

## 全球通关榜

大厅和结算页显示所有玩家共享的前三名，十七关各自按 1 / 2 / 3 / 6 人分别排名。用时越短排名越高；同一玩家、或相同成员组成的队伍，只保留最快一次。相同时间按先达成者优先；显示精确到小数点后一位，比较使用毫秒。

通关会自动提交，昵称公开显示。浏览器保存随机匿名标识，服务器仅保存其哈希；不需要注册。更换浏览器或清除浏览器数据会被视为新玩家，昵称不作为身份依据。

昵称使用同一份前后端词库审核：大厅出发、创建和加入房间、单人上传成绩均检查。服务器拒绝违规昵称并返回 HTTP 422，即使绕过网页也无法用该昵称报名或上榜。简繁体（词库涉及的字）、全角、大小写、拉丁字母重音、空格、标点及隐形字符会归一后匹配，原始输入和最终截取的昵称都要通过。展示最多 16 个 UTF-16 单元，不截断单个 Unicode 码点；空昵称使用「旅人」。过长原始请求先拒绝，避免不必要的处理开销。

维护词库：编辑 `src/name-terms.ts`，长词放 `BLOCKED_NAME_FRAGMENTS`（包含匹配），容易误伤的短缩写放 `BLOCKED_EXACT_NAMES`（完整匹配），然后运行测试、重新构建并同步部署网页与 Worker。该列表是游戏自己的昵称规则，不是权威违禁词清单；未列入的谐音、变体不会自动识别，需按运营情况维护。不要添加普通地名、单字姓氏或过短拼音，以免误伤正常昵称。

读取旧房间、旧榜单时也应用当前规则，命中的名字显示为「旅人」，成绩、名次和队友保留。旧多人待上传成绩同样遮蔽名字后入榜，避免永久重试。若单人通关时遇到服务器词库更新，可在结算页使用「旅人」重试上传原成绩，无需重玩。不记录命中的原始昵称到服务日志。

单人将压缩后的逐帧操作提交到服务器重演，只接受实际通关并由重演得出的时间；联机由房间服务器直接提交。核验可防止直接填写假时间，并不等于专业赛事的反作弊系统。单人记录上限为两小时、32768 段操作，接口体积上限 512 KiB；超限仍可正常游玩并保留本地最佳。断网不影响单人，结算页可重试上传；离开结算页前请完成重试。联机待提交成绩写入持久队列，断线、重开或房间过期后继续重试。

此前只存在本地的旧纪录没有通关过程，不能补入全球榜。从本次更新后的通关开始记录，原有本地最佳保留。每个版本、关卡、人数使用独立 SQLite Durable Object；地图或影响计时的物理规则改变时，应更新 `src/leaderboard.ts` 的 `RANKING_VERSION`。

榜单接口测试只允许本地服务，避免把测试成绩写进正式排行榜：

```sh
npm run test:leaderboard
```

## 发布

GitHub Pages 托管前端，Cloudflare Workers + Durable Objects 托管联机房间。

- GitHub 仓库 Pages 来源为 **GitHub Actions**，推送 main 后自动测试、构建并发布。
- 默认房间服务写在 `.env.production` 和发布工作流的公开配置中。可使用仓库变量 `VITE_ROOM_SERVER_URL` 覆盖。
- `wrangler.jsonc` 的 `ALLOWED_ORIGINS` 已包含 `https://ctrlcctrlvisthebest.github.io`。如换域名，增加其 origin 后重新部署后端。
- 资源路径使用 `./`，适用于 GitHub Pages 仓库子路径。

重新发布房间服务及备用入口：

```sh
npm run build
npm run deploy:server
```

部署凭证由本机 Wrangler 管理，不放入网页或仓库。浏览器的房间座位凭证只保存在自己的 sessionStorage，通过 WebSocket 首次认证消息或 HTTPS Authorization 头发送，不放入邀请链接。

Cloudflare 用量取决于账号方案和游戏时长。房间在无连接和过关时停止模拟，有创建频率限制，并在 24 小时后清理。

## 结构

- `src/game.ts`：确定性 60 Hz 物理、收集/失败判定与前四关。
- `src/chapters.ts`：第五至八关的手工路线、收集物、存档点与天气。
- `src/maps/*.json`、`src/challenge-maps.ts`：第九至十七关的完整地图文件与统一注册。
- `editor.html`、`src/editor*.tsx`、`src/editor-model.ts`：独立搭建界面、地图操作和共用引擎试玩。
- `src/map-format.ts`、`MAP_FORMAT.md`：地图格式、校验器与接入说明。
- `src/collectibles.ts`：物品归属、存档、死亡回滚与旧房间迁移。
- `src/weather.ts`：雨区、檐亭、小火堆、烘干与降温参数。
- `src/fire-scene.ts`：石圈、木柴、火焰、火星与烘烤范围圈。
- `src/scene.ts`：Three.js 纸鹤、平台、光照、相机旋转与动画。
- `src/main.tsx`、`src/style.css`：大厅、操作、HUD、触屏按键、结算。
- `src/guide.ts`：十七关目标步骤、方向提示、存档回退与情境提示。
- `src/guide-ui.tsx`：当前目标卡、通关目标和七类双语玩法图解。
- `src/i18n.ts`：中文、英文界面和路牌翻译。
- `src/audio.tsx`：背景音乐、音量、后台暂停和音效。
- `src/api.ts`：房间请求、WebSocket 与自动重连。
- `src/room.ts`：人数、权限、加入与投票。
- `server/worker.ts`：房间路由、权威模拟、SQLite 存档与过期回收。
- `tests/journey.ts`、`tests/chapter-journeys.ts`、`tests/storm-journeys.ts`：使用正常输入完成十七关的自动化路线。
- `.github/workflows/pages.yml`：Pages 自动发布。

几何纸鹤、平台和音效由代码生成；没有复用 SpriteQuest 或 PICO PARK 的关卡、美术或音频。字体为 Google Fonts Noto 系列，有系统字体回退。
