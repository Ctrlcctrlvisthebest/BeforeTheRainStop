# UI 与关卡标题交付

灰蓝雨幕、木色挂签和暖灯主操作；中文竖排题字，英文横排，手机单列。保留日式建筑和大尺寸触控键。雨幕跟随关卡高度并受屋檐、渡舟、纸面遮挡；风柱改为三缕柔边渐隐气流。

完整分析见 [四十关标题审阅](level-title-review.md)，设计规范见 [DESIGN.md](../DESIGN.md)。

## 2026-09-13 反馈修订

去除状态 / 引导 / 计时 / 存档的卡片外框与底块；触控改为淡纸面，移除厚边、阴影和红色跳跃键，保持热区尺寸。第 40 关改为「旧灯归途」，英文 Back to the Old Lantern，不预设终章。风效重新实现为三缕渐隐薄雾带，不再绘制螺旋线与纸屑。

本轮复测：风雨、触控、存档 31 项及 UI 22 项，合计 53 项通过。浏览器验证 390px 手机布局、桌面状态栏、风口正侧视角；着色器无报错。

### 硬边风效

按用户补充，柔边雾带已撤下。现在每个风口是五片硬边折纸，以两块纯色三角面表示折痕，靠上升与轻微翻转表现风；无虚化、发光、软边或透明渐变。风力、范围、地图与雨效保持不变。

### 上升叶片修订

按用户要求将风口折纸片换成灰绿色叶子，具有尖叶、叶脉、短叶柄，向上飘动并轻微摆动翻转。保持硬边、原风力与风口范围。

叶片最新调整：改为暖黄色，整体缩小 25%；运动、数量与风力保持原样。
