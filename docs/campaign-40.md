# 第 28–40 关：进阶挑战

2.11.0 在原 27 关之后新增 13 关。原关的地形、天气、机关、引导和名字保持原样。新关各用独立 JSON 文件，同时注册到游戏、编辑器模板、引导、联机服务与排行榜重放。

## 难度与路线区别

新关把原本分开学习的动作连续组合起来：常规落台宽深以 2.6 为主，转向后需重新找准起跳位置；上升步高多为 0.8–1.1，风柱抬升 3.6–4.6；渡舟跨越约 13 的长断口，不能直接滑翔越过。每关至少六次跳跃、三个独立互动模块，后段逐步增加组合长度与转换次数。难度来自操作衔接和观察时机，保留中途存档与烘干点。

| 关卡        | 独立模块              | 主要组合与区别                                         |
| ----------- | --------------------- | ------------------------------------------------------ |
| 28 天缝针脚 | 2 风 + 1 舟           | 横纵窄台交错，两次风升夹着反向渡舟，尾段向外下降       |
| 29 烬火换舟 | 3 舟                  | 两段火檐紧接不同方向的登舟点，三次换乘后跳回低岸       |
| 30 封檐栈道 | 门 + 桥 + 风 + 舟     | 先开闸再侧向接纸桥，登高后从另一侧下降到渡舟           |
| 31 碎拍长歌 | 桥 + 风 + 舟          | 四段不同周期的火檐，纸桥、升空和渡舟穿插其中           |
| 32 云间榫口 | 2 舟 + 2 风           | 低处横渡与高处反向跨越叠成榫口，最后走高层折线         |
| 33 四时桅索 | 门 + 桥 + 风 + 2 舟   | 火后开闸，船上起跳摘钥，高层回转接桥后再换舟           |
| 34 逆瀑回声 | 3 风 + 2 舟           | 两次大幅下降后重新借风爬升，不同高度的舟相向行驶       |
| 35 穿针暗渡 | 桥 + 门 + 2 风        | 短檐、侧台存档、纸桥与双风窄阶，先接桥后开闸           |
| 36 三叶潮汐 | 3 舟 + 风             | 东、北、西三向转乘，首舟摘高钥，最后通过风火阶梯       |
| 37 悬空密札 | 2 风 + 门 + 舟 + 桥   | 高层开闸后连续下落，渡舟与低层纸桥连接最后上升段       |
| 38 风暴织机 | 3 风 + 2 舟 + 桥      | 风和舟交替织出两层路线，中段双火变拍与侧台存档         |
| 39 长夜守灯 | 2 舟 + 2 风 + 门 + 桥 | 两次船上高钥、火檐前后换面，后半程再升空搭桥           |
| 40 雨尽天阶 | 3 舟 + 2 风 + 门 + 桥 | 四类机关与两段火檐综合考验，下降后重新登高，末段三连跳 |

重复访问同一机关不重复计数；同一扇门的两块踏板计为一个模块。火焰额外增加时机判断，不纳入互动模块数量。

平台（含移动台、门、檐、栏杆）的宽深与同高拼接后的连续直路均不超过 9。转向段保留实际断口；纸桥低檐与侧栏阻止直接跳过。采用现有渲染方式，不增加平台白色描边或整片高墙。桥口和踏板等待区避开烘干火堆，第 35、38 关桥前的烘干存档点移到侧台。

## 验证

- 每个新关在 1 / 2 / 3 / 6 人和 0 / 90 / 210 / 330 帧出发延迟下完成全星、全员无死亡通关，共 208 组；全过程使用移动、转面、跳跃、展纸和折桥输入，没有传送或注入钥匙。
- 所有渡舟断口移除移动平台后不能直接滑翔越过；所有纸桥验证跑、跳、滑翔均无法穿过低檐断口，并覆盖松手重新折桥、六人逐个接应。
- 检查地图格式、支撑、六人安全出生区、平台规则、中英文文本、40 关顺序推进及最终回到第一关。
- 地形规范化比较排除平移、镜像、交换两轴后的整图重复。
- 本地真实 WebSocket 测试覆盖新增 28、40 关的成员座位、转面同步与重连；第 40 关全星操作提交本地 Worker 重放，验证新关排行榜与旧协议拒绝。

## 成绩与发布

协议版本提升至 7，使 27 关旧客户端在连接新服务时提示刷新。本地 v6 的前 27 关成绩按关名和人数完整迁移；旧版本更早重做过的地图仍保持历史隔离。全球榜沿用前 27 关既有分区，新关使用独立关名分区。两首 BGM、手机控制和浏览器兼容修复保持原样。

GitHub Pages 与专用房间 Worker 一起更新。`dist-toy` 也生成相同的 40 关前端；本次生成本地包，不代表 Toy 平台审核或线上发布已经完成。旧 17 关 Toy 的独立 Worker 保持原样。
