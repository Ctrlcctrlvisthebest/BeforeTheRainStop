# 第 28–40 关：解谜与动作交错

2.12.0 重做第 29、30、32、34、35、36、40 关。第 1–27 关，以及 28、31、33、37、38、39 六个操作关，保留原来的地图。重做的地图仍使用独立 JSON，同时用于游戏、编辑器模板、引导、联机与排行榜重放。

## 设计原则

撤销“每关至少六次跳跃、三个机关”的统一指标。所有平台的宽、深和同高拼接后的连续直路仍不得超过 9；第 11 关起仍至少包含两个独立互动模块。同一舟的往返、同一座桥的再次通行、同一门的两块踏板都只计一个模块。

关卡难度从路线决策和操作方式体现：楼上控制楼下的门、回访同一处存档、一次跳跃中的空中转面，以及没有中间岸的船间换乘。保留的操作关穿插其中，避免连续十三关都按“连跳—机关—新存档”推进。火焰提供额外的时机判断，不计入模块数；未改动渲染器，没有新增描边或大块墙体。

## 可回访存档、空中转面与换乘

第 29、30、32、35、40 关启用 `level.freeCheckpoints`：任意许愿架可保存新物品，最后停靠的架子成为复活点。返回同一架子不会自动补充耐折，可按 F 修补。其他关卡继续使用原来的依次存档规则。界面及图解按本关规则显示。

跳跃引导可带 `via` 空中转弯点：`view` 是起跳时的方向，到达转弯点后保持跳跃并切换另一轴。渡舟引导可带 `landingId`，引用下一座移动平台；换乘标记随目标船移动，并在交会窗口提示起跳。编辑器可设置两种引导，导入导出保留字段，删除平台会清理或调整换乘引用。

## 验证

- 第 28–40 关在 1 / 2 / 3 / 6 人，以及 0 / 90 / 210 / 330 帧出发延迟下全星、全员无死亡通关，共 208 组。使用真实移动、跳跃、滑翔、转面和搭桥输入，不注入玩家位置或收集状态。
- 单独检查同舟往返、上层开闸后返回旧架、同桥重复通行、三次空中换轴、船间直接换乘和终关环路。第 35 关额外验证四种人数反向选择钥匙分支；移除中央烘干能力后原全星路线会淋湿失败。
- 所有渡舟断口检查无法直接跳过；纸桥检查低檐、取消重搭、2 / 3 / 6 人逐个接应。存档点和小火避开桥头的等候区域。
- 保留四十关的地图格式、六人安全出生、落点支撑、连续地面、中英文、流程推进和完整重放验证。
- 测试可回访架子的存物及死亡恢复、旧关依次存档、引导重入、编辑器引用修正，以及新旧成绩隔离。
