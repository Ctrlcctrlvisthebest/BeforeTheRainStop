# 小红书《雨停之前》离线单人版

基于游戏 2.13.0，包含全部 40 关。地图、顺序、关卡 ID、物理规则和本地成绩键保持不变。小红书包只有单人入口；联机、房间邀请、公开昵称及全球榜不进入运行产物。

## 交付文件

- `releases/before-the-rain-xhs-solo-2.13.0.zip`：保留《沿灯而行》《檐下的愿望》两首原有 BGM，约 3.15 MiB。
- `releases/before-the-rain-xhs-solo-2.13.0-no-music.zip`：无音频上传包，约 0.32 MiB。平台已确认拒绝 m4a，请上传此包。

直接上传 ZIP，不需要解压或再套一层目录。入口 `index.html` 位于根目录，所有脚本、样式、图片和媒体均为包内相对路径。没有相册、相机、麦克风或其他原生权限需求。本地记录和偏好使用容器内的 localStorage；不会同步外部排行榜，清除小工具数据可能丢失记录。

平台已在实际上传时拒绝 `audio/lantern-walk.m4a`。因此小红书使用无音乐包；音乐归档仍保留两首原曲，不改后缀、不伪装文件类型。

## 界面恢复（2026-09-15）

按用户要求撤销适配时额外修改的外观。四份共享样式 `style.css`、`mobile.css`、`play-layout.css`、`rain-ui.css` 未改；去掉小红书专用字体、焦点描边和引导控件隐藏规则。尺寸与安全区回退仅对不支持原 CSS 功能的旧内核生效，现代内核保留原来的 clamp 值。

恢复发布版的三维场景、阴影、硬边火焰与火星、雨幕和小黄叶。离线场景加载器只改为静态加载同一个 `PaperScene`，不再根据帧率或绘制次数切成另一套二维画面；删除该二维实现。没有 WebGL2 时使用游戏原有加载失败与重试界面。以后平台适配不得自行改变 UI 或替换画面表现。


## 构建

```sh
npm run build:minitool
npm run test:minitool
```

构建先检查 40 关地图规则和 TypeScript，再分别生成音乐版和备用版、进行静态能力检查并压缩。打包脚本需要 Node 和 Python 3；压缩只用 Python 标准库。构建输出独立于 `dist` / `dist-toy`，原有普通版和 Toy 构建命令继续保留联机功能。

- 经典 IIFE 脚本，面向 Chrome 61 编译，无模块加载、动态 import 或内联脚本。
- 构建别名隔离网络模块；额外去除 React 的网络信息探测。产物扫描拒绝请求、连接、剪贴板、Worker、动态执行代码等受限能力。
- 兼容 structuredClone、Object.hasOwn/fromEntries、flatMap/at、randomUUID、旧 matchMedia 和 ResizeObserver。快照克隆保留 Infinity，避免 JSON 克隆损坏数值。
- CSS 编译提供旧语法与必要布局回退，保持原有控件外观、位置和触控区域。
- 共用发布版的完整三维场景，游戏循环 30 FPS。恢复原画面后不再执行之前的 100/50 次绘制预算切换，也不保证低配设备达到原降级版的性能预算。
- 切后台停止游戏循环、清空输入并暂停音乐；重新显示时重置时间差。切关释放实例缓冲区、材质和纹理。

## 本次验证

- TypeScript、40 关地图规则、音乐和无音乐两种构建通过。
- 单人版 4 项、界面/触控/音乐 22 项、渲染资源/天气 26 项测试通过。
- 浏览器对照原有共享 CSS 与恢复版的手机入口、HUD 和按键；恢复版显示原三维场景。
- 全部 40 关共 3,044 处双视角渲染取样通过，全部使用原 3D 场景，无二维切换。最大绘制提交 776、三角形 28,993；这是渲染检查，不等同于真人通关或小红书真机性能验证。
- ZIP 根目录入口、文件类型、包内相对资源与受限能力检查通过；无音乐包中没有音频文件。

未在小红书真机容器或真正的 Chrome 61 上实测。本次没有上传、发布、提交或推送代码。
