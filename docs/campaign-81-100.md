# 第 81–100 关：分层院落

这一组使用现有物理和机关，增加的是路线、落点和收集关系。第一至四十关保持原状。全部新图支持 1 / 2 / 3 / 6 人，不把多人专用动作当成单人通关前提。第 100 关叫「又见一庭」，出口仍指向下一段旅程，不定义为终章。

每关都有独立的静态 JSON 地图、中文标题和说明、英文翻译、物品与检查点、实际路线引导。注册位于 `src/campaign-81-100.ts`，最终由统一地图校验器检查。没有增加一种只服务某个关卡的生产代码分支。

## 布局与可读性

- 所有实体平台的宽度和深度不超过 9，连接后的同高固定直路也不超过 9；小于 0.8 的接缝仍按连续地面检查。
- 每关至少两个在路线里实际使用的独立互动模块。三次经过同一条船或同一座桥不重复计数。
- 没有为堆难度添加大型墙体。低檐和栏杆仅用于明确的纸桥断口，主体空间由短台、分层、断口和换面构成。
- 安全亭放在主要中继台，出生亭覆盖六个起始座位。全部座位连续等待一分钟验证湿度、热度与死亡次数均为零。火源避开长时间等船或站板的位置，避免安全等待变成烤脆陷阱。起手渡舟的最内靠岸位置和风区入口也与六个出生位分离，等待队友时不会被船带走或被风托离起点。
- 91 / 96 起手使用风井，86 / 89 / 93 / 97 起手渡舟，90 起手开门，83 / 85 / 88 / 98 起手空中下降，其余用短跳进入院落。没有给所有关复用同一个开场动作。

## 验证

`tests/campaign-81-100.test.ts` 对每关运行四种人数和四个出发延迟（0 / 90 / 210 / 330 帧），共 320 次真实输入全星无死亡通关。不传送、不注入位置、不手动打开机关。平台尺寸、连续地面、引用和落点警告全部检查。

另外验证无风无法继续上层路线、取消搭桥无法通过有檐断口，并观测实际游戏事件：81 的两次回枢纽、83 的三层下降与高庭回访、84 的桥后回庭、88 的两次空中转面、89 的船上腾空取钥、90 的出生楼层开门、91 的三条独立风道、99 的原舟往返和 100 的四类机关完成情况。
