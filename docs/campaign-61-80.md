# 第 61–80 关：节拍、换舷与错层落点

这组关卡将动作时机和空间判断放在前面。第 41–60 关侧重回访与分岔，这里则让低檐火窗、侧向登舟、船间换乘、空中转面和升降路线交替成为主任务。所有关卡保留两种语言和 1 / 2 / 3 / 6 人路线。

| 关  | 名称     | 实际主要任务与空间安排                                                               | 与邻关及旧关的区别                                                                                   |
| --- | -------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| 61  | 檐火换舷 | 从高处火窗起步，纵舟过水后空折下降，再朝相反方向升风。                               | 先等火再赶舟，之后下降和反升；不沿旧 28 的连续上升阶路线。                                           |
| 62  | 叶港接舷 | 风口先送上高港；沿纵向第一条舟起航，在空中接上横向第二条舟；远岸穿短火檐。           | 舟间没有固定中转台，需真正跳到另一条运动中的舟；与旧 36 的低层直入双舟不同，换乘前后还有高风与火窗。 |
| 63  | 斜雨双岸 | 正向横渡、纵向登风后，沿更高的另一条横舟逆向通过；末尾向低处转面降落。               | 两条相反航道在不同高度，玩家需要认清高低岸线，不能简单按最近的渡口前进。                             |

## 尺寸与机关约束

- 所有实体平台、低檐、栏杆及闸门的宽度和深度均不超过 9。
- 校验器检查固定地面的同高并集，拼接平台和小于 0.8 的缝隙不能绕过直路上限。
- 每关至少两处独立互动模块；火窗和普通跳阶额外提供动作要求，不拿它们冒充渡舟、风、纸桥、石板门的数量。
- 复访同一机关只计算一次。第 62 关的两条船拥有独立运动平台，并且必须在船间起跳。
- 起点火窗留足六名玩家的出生位置；等待船靠岸的檐下火堆偏离等候点，角色可主动靠近烘干，站着等船不会被迫烤脆。

## 验证

`tests/campaign-61-80.test.ts` 对每一关以四种人数、四个出发时刻跟随公开路线完成普通操作，共 320 组全星无死亡通关。测试额外核实每艘路线渡船实际承载过角色、每个风柱实际托举过角色、纸桥和石板闸实际接通，并逐关验证禁止跳跃后无法按该路线通关。

舟间换乘、侧向登舟和空中转面均使用实际按键完成。测试驾驶器在横渡舟上通过转面和方向操作对齐甲板；生产物理规则保持原状。
