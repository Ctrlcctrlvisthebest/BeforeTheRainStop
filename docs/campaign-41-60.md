# 第 41–60 关：庭院、回程与层间路线

这些关卡使用现有物理和四类互动机关，没有增加独立的关卡脚本。路线、实体、天气和中英文文案都在对应 JSON 中；关名依据实际空间与行动安排。

## 逐关设计与区分

| ---- | -------- | ---------------------------------------------------------------------------------------- | ---------------------------- | ---------------------------------------------------------------------------------------- |

| 42   | 层间门影 | 出生庭先分站踏板开闸，穿过门前短阶，再沿向北和向西的两股风跨到庭背                       | 踏板门、两股风               | 开场就要开门，不沿用旧 30 关“上楼开闸再回原门”的流程；两把钥匙分居不同高台               |

## 地图约束

- 所有碰撞平台、低檐、栏杆和门的宽与深均不超过 9；固定连续地面按实际并集检查，不能用小接缝拆分规避。
- 每关有 2–4 个路线实际使用的独立互动模块；同一艘船的往返只计一个。
- 出生区容纳六名角色的初始排布。回程台面与出发路线之间留出真实头部空间，不能让上层平台变成不可见的起跳障碍。
- 41、46、50、55、58、60 在桥后布置短檐脉冲火，火焰位于远岸踏板之后，不会把保持桥形的玩家放进火焰里。
- 许愿架附近的烘火位置与桥板等待点错开，避免多人接桥时因站位固定而被迫烤脆。
- 保留雨幕、檐亭、火光和小平台的整体表现；没有通过大墙或长黑色实体填满画面。

## 验证

`tests/campaign-41-60.test.ts` 使用现有 `completeStormLevel`，以正常方向、跳跃、转面、纸桥等输入完成路线。没有传送、直接改角色坐标或注入机关状态。

- 每关覆盖 1、2、3、6 人和 0、90、210、330 帧出发时刻，共 **320 组全星、无死亡、全员到达**。
- 六个出生席位分别无输入等待61秒，要求零死亡、零热度、零湿度；风口不覆盖等待中的出生席位。
- 每关单独记录真实拾钥位置、登船次数、风柱使用以及门/桥开通时的钥匙数，验证表中具体体验。
- 禁用跳跃、禁用转面后，所有关卡的对应路线都无法完成。
- 带纸桥的关卡禁用纸桥输入后无法完成，验证低檐断口的机关必要性。
- 全组通过平台尺寸、连续地面长度及独立互动模块规则检查。
